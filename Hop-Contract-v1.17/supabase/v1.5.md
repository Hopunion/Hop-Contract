# v1.5 database migration

Run `v1.5-migration.sql` once in Supabase SQL Editor before deploying the v1.5 frontend.

It adds the `current_contract_total_kg` comparison field and recreates the cloud load/save functions so the value persists.

Because v1.5 auto-saves edits, automatic pre-save snapshots are throttled to one per 15-minute window. Named snapshots remain available at any time.

No historical production volumes or recipe history are rewritten by this migration.
