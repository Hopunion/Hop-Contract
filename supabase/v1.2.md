# v1.2 database change

Adds `hop_inventory.supplier_received_last_12m_kg` and updates the Supabase state RPCs.

This value is a historical supplier receipt **cross-check only**. It is returned to the frontend and saved with Inventory, but it is not used by PostgreSQL or the frontend contract formula.

The migration also retains the v1.1 recipe-to-inventory UUID link foundation.
